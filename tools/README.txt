Q-board Raw Input Bridge / Q-board 外接键盘桥接器

Windows 使用方法：
1. 下载并运行单文件安装器 QBoardBridgeInstaller.exe。
2. 选择安装目录；安装器会安装 QBoardBridge.exe、注册网页启动协议并复制目录路径。
3. 将路径粘贴到 Q-board 的“本地桥接器连接”，或直接浏览该目录。
4. 点击“打开桥接器”，确认网页左侧窄面板显示已连接。
5. 点击“+”添加键盘，再按一下要绑定的实体键盘；每增加一把键盘重复一次。

如果浏览器询问是否允许访问本地网络，请选择允许。
程序未签名，Windows 首次运行时可能显示安全提示。

旧版 qboard-rawinput-bridge.zip 和 PowerShell 启动器仅作为兼容备用。

English:
1. Download and run the single-file `QBoardBridgeInstaller.exe`.
2. Choose an install folder. The installer deploys `QBoardBridge.exe`, registers the web launch protocol, and copies the folder path.
3. Paste the path into Local bridge connection, or browse to that folder.
4. Click Open bridge and wait for the narrow web panel to show Connected.
5. Click +, then press one key on the physical keyboard to bind it. Repeat for each keyboard.

Allow local-network access if the browser asks for permission.
The executables are unsigned, so Windows may show a first-run warning.

The old ZIP and PowerShell launcher remain available only as a compatibility fallback.
